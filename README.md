# jerchenxin.github.io

Personal academic homepage of Xin Chen, hosted on GitHub Pages.

## Local Preview

Start a local HTTP server from the repository root:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000` in a browser.

Press `Ctrl+C` in the terminal to stop the server.

## Archived Writing

The Markdown files under `posts/` are retained as source archives. They are excluded
from GitHub Pages publishing through `_config.yml`.
